# Evidence Grading System

## A – Primary Record
Original document:
- Birth certificate
- Death certificate
- Probate file
- Military pension
- Land deed
- Census image (not transcription)

## B – Transcribed Primary
- Headstone transcription
- County marriage index
- Published document quoting primary record

## C – Secondary Published Source
- Book without primary citation
- Compiled genealogy
- Memorial narrative

## D – Family Narrative
- Oral history
- Unsourced internet tree
- Family letter without supporting documentation

No lineage link may be graded D.
