🏷 Canonical Identity Format (CID)

Every individual is assigned:

```
<NS>-<BirthYear>-<Sequence>-<BirthState>
```

Example:

```
RND-1796-001-TN  (Ruben Randolph)
RND-1827-001-TN  (Isaac Randolph)
RND-1853-001-MO  (Elijah Randolph)
```
Namespace:
```
RND = Randolph
```

This prevents:
	•	Duplicate names
	•	Sr/Jr confusion
	•	Cross-generation errors
	•	Variant spelling errors
