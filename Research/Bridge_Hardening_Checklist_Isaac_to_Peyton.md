# Bridge Hardening Checklist
## Isaac Randolph → Ruben Randolph → Peyton Randolph Sr

This checklist defines the evidence required to elevate the Tennessee bridge from Grade B to Grade A.

---

# 1️⃣ Isaac Randolph (1827–1888)

### Required Primary Evidence

[ ] 1850 Census image (White or Cumberland County, TN)
[ ] 1860 Census image
[ ] Marriage record (Isaac + Juda Cooper) image
[ ] Probate record (Benton County, AR)
[ ] Land deed (Tennessee or Arkansas)
[ ] Death certificate or probate summary

Goal:
Confirm Isaac as biological son of Ruben Randolph in a primary document.

[ ] Probate file (Cumberland County, TN)
[ ] Land grant / deed file

Direct documentary confirmation of Isaac as named son.

---

# 3️⃣ Peyton Randolph Sr (c1760–1851)

Goal:
Document Peyton’s origin state with primary proof.
